# Auth + Painéis SaaS — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar o Prospecta em SaaS pago com cadastro, login, recuperação de senha, painel do cliente e painel de admin.

**Architecture:** Clerk lida com auth (registro, login, e-mail, reset de senha); um D1 guarda usuários e contadores de uso; o middleware valida o JWT do Clerk e injeta o `clerk_id` nos requests; cada endpoint de quota lê e incrementa o D1.

**Tech Stack:** Clerk (`@clerk/backend` no Worker, `@clerk/clerk-react` no frontend), Cloudflare D1, Cloudflare Pages Functions (TypeScript), React + Vite.

**Spec:** `docs/superpowers/specs/2026-11-11-auth-design.md`

## Global Constraints

- Plano único: 200 buscas/mês, aviso aos 20 buscas/dia, 50 prévias/mês. Sem trial, sem free.
- Teto de resultados por busca: 50 (validation.ts).
- Cache de busca: 7 dias (era 24h).
- Admin = e-mail `web.danillo@gmail.com` (via Clerk metadata `role: 'admin'`).
- Usuário sem `active = 1` no D1 → 403 "Conta ainda não ativada."
- Nenhuma chave/segredo vaza para o front: `CLERK_SECRET_KEY` e `CLERK_PUBLISHABLE_KEY` ficam em variáveis de ambiente.
- `npm run check` deve passar ao final de cada task.

## Review Focus

- Usuário ativo que esgota as 200 buscas → próxima busca deve retornar 429, não 500 ou resultado vazio.
- Usuário inativo (cadastrou mas não foi ativado) → 403 em toda chamada de API.
- Cache de 7 dias: busca igual dentro da janela não incrementa o contador de quota.
- Admin tenta acessar `/api/admin/*` via outro usuário → 403.
- Aviso de 20 buscas/dia: contador diário é por UTC (zera à meia-noite UTC), não por horário local.

### Task 4: `server/quota.ts` — verificação e incremento de uso no D1

**Files:**

**Interfaces:**

  - `checkQuota(db: D1Database, clerkId: string, action: 'search' | 'preview'): Promise<QuotaResult>`
  - `incrementQuota(db: D1Database, clerkId: string, action: 'search' | 'preview'): Promise<void>`
  - `QuotaResult = { allowed: boolean; remaining: number; dailySearches: number; reason?: string }`

Limites (constantes exportadas):
- `MONTHLY_SEARCHES = 200`
- `MONTHLY_PREVIEWS = 50`
- `DAILY_SEARCH_WARN = 20`

- [ ] **Step 1: Escrever testes**

```typescript
  it('monthly searches limit is 200', () => expect(MONTHLY_SEARCHES).toBe(200));
  it('daily warn threshold is 20', () => expect(DAILY_SEARCH_WARN).toBe(20));
});
```

- [ ] **Step 2: Rodar para confirmar falha**

```bash

```

- [ ] **Step 3: Implementar `server/quota.ts`**

`ensureUser`: `INSERT OR IGNORE INTO users (clerk_id, email) VALUES (?, ?)` — cria linha com `active=0` se não existir. Retorna `{ active: row.active === 1 }`.

`checkQuota`: Ler `usage` para o mês atual (formato `YYYY-MM`) e `usage_daily` para hoje (formato `YYYY-MM-DD`). Retornar `{ allowed, remaining, dailySearches }`. Para `search`: allowed = `searches < MONTHLY_SEARCHES`. Para `preview`: allowed = `previews < MONTHLY_PREVIEWS`.

`incrementQuota`: `INSERT OR REPLACE INTO usage ...` incrementando a coluna correta. Para `search`, também `INSERT OR REPLACE INTO usage_daily ...`.


- [ ] **Step 3: Atualizar `functions/api/search.ts`**

a. Mudar `const TTL = 60 * 60 * 24` → `const TTL = 60 * 60 * 24 * 7`.

b. Adicionar `cachedAt: number` ao objeto retornado por `produce()`: `{ results, outcome, cachedAt: Date.now() }`.

c. No início do handler, antes da busca:
1. Ler `clerkId` de `request.headers.get('x-clerk-id')` — se ausente, 401.

5. Se `!allowed` → 429 com mensagem "Você atingiu o limite de 200 buscas este mês. Renova em [data]."
6. Se `dailySearches >= DAILY_SEARCH_WARN` → incluir `warning: "Você já fez X buscas hoje."` na resposta (não bloqueia).

d. Após a busca bem-sucedida: `await incrementQuota(env.DB!, clerkId, 'search')`.

e. Adicionar `cachedAt` e `warning` ao tipo `SearchResponse` ou retornar via JSON direto.

Padrão idêntico ao search: `ensureUser` → verificar active → `checkQuota` → executar → `incrementQuota`.
