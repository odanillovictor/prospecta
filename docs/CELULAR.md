# Usar o Prospecta no celular (mesmo Wi-Fi do PC)

## Passo a passo
1. No PC, dê **dois cliques** em `Abrir Prospecta no celular.bat` (fica na pasta `Danillo crm`).
2. Se o Windows perguntar sobre o firewall, clique em **Permitir** (Redes privadas).
3. Aguarde o quadro com o endereço `http://192.168.x.x:8788/#coletor=...`.
4. No celular (mesmo Wi-Fi, sem VPN), **aponte a câmera para o QR code** da janela (não precisa copiar nada). Ou digite o endereço inteiro. O link também fica copiado no PC (Ctrl+V).
5. Se o app pedir o código de acesso, digite em Ajustes.
6. Busque no Google Maps normalmente.

## Regras
- Quando o código mudar, **não precisa reiniciar**: espere uns 15 segundos e recarregue a página no celular (puxe para baixo).
- Deixe a janela do `.bat` aberta; fechar derruba o acesso. Não selecione texto nela (pausa o programa).
- Se o endereço mudar (IP do PC), use o novo que aparecer na janela.
- Os leads do celular ficam separados dos do PC (Ajustes → Exportar/Importar backup).

## Se der erro
- "O coletor não respondeu": abra de novo o endereço COMPLETO (com `#coletor=...`).
- Página não abre: conferir mesmo Wi-Fi e firewall.
